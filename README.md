ZENVIA | زنویا

محصولات شرکت بیز، به قیمت کارخانه

زنویا یک فروشگاه اینترنتی برای معرفی و فروش محصولات شرکت بیز است. این پروژه با هدف ایجاد تجربه خرید ساده، سریع و مطمئن طراحی شده است.

امکانات فروشگاه

- نمایش محصولات واقعی ثبت‌شده توسط مدیر
- دسته‌بندی محصولات
- جست‌وجو و مرتب‌سازی محصولات
- صفحه اختصاصی هر محصول
- سبد خرید
- ثبت و پیگیری سفارش‌ها
- حساب کاربری مشتریان
- پنل مدیریت اختصاصی
- افزودن، ویرایش و حذف محصولات
- آپلود تصاویر محصولات از گالری گوشی
- مدیریت سفارش‌ها و موجودی
- دستیار خرید هوشمند مبتنی بر محصولات واقعی فروشگاه

مدیریت محصولات

هیچ محصول نمونه یا اطلاعات ساختگی از قبل در فروشگاه قرار نمی‌گیرد. محصولات پس از ثبت توسط مدیر در پایگاه داده مرکزی ذخیره و برای بازدیدکنندگان نمایش داده می‌شوند.

امنیت

- استفاده از Supabase Authentication
- کنترل دسترسی مدیر
- استفاده از Row Level Security
- نگهداری کلیدهای محرمانه در سمت سرور
- عدم قرار دادن کلید Service Role در کدهای عمومی سایت

وضعیت پروژه

پروژه در مرحله توسعه و اتصال بخش‌های مختلف قرار دارد. فعال شدن امکانات نهایی به تکمیل تنظیمات Supabase، جداول پایگاه داده و سیاست‌های امنیتی وابسته است.
